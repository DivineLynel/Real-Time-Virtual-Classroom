# 🚀 Real-Time Virtual Classroom

A live, collaborative digital learning platform built to connect students and teachers instantly. This application features a real-time digital drawing whiteboard, isolated quiz rooms, and live classroom leaderboards. 

Instead of just building a static website, this project focuses on **high-performance, live data synchronization** meaning when one user draws or answers a question, everyone else in the classroom sees it instantly without refreshing the page.

---

## 💻 Tech Stack & Key Features

-   **Backend Framework: Python (Flask)** acts as the core server engine.
-   **Real-Time Data: Flask-SocketIO (WebSockets)** powers the low-latency, two-way communication channel between the server and users.
-   **Database:  SQLite** securely saves custom quiz questions and scoreboard rankings so data isn't lost if the server restarts.
-   **Frontend Design:  HTML5, CSS3, and Native JavaScript** handle smooth screen rendering, mouse movement tracking, and interactive button clicks.

---

## 🛠️ Advanced Engineering Challenges Solved

### 1. Multi-Classroom Isolation (Multi-Tenancy)
-   **The Problem:** Preventing students in Room A from seeing drawings or quiz scores from Room B.
-   **The Solution:** Leveraged Socket.io "rooms" to dynamically separate students by their unique room codes. This ensures complete data privacy so data streams never cross-contaminate.

### 2. Fair Quiz Timing & Anti-Cheat Logic
-   **The Problem:** If quiz countdowns run on the user's computer browser, variations in computer speeds or intentional clock manipulation can let users cheat on answer deadlines.
-   **The Solution:** Built a central **background clock thread on the Python server**. The server manages the second-by-second countdown ticks and broadcasts them to everyone at the exact same time, preventing late answer submissions.

### 3. Persistent Scoreboards & Efficient Queries
-   **The Problem:** Keeping temporary scores in server memory (RAM) is risky; if the server crashes mid-quiz, all data vanishes.
-   **The Solution:** Transitioned temporary player scores and quiz banks into a structured SQL database. Implemented database optimization to ensure fast query lookups without lagging the real-time gameplay.

### 4. Smooth Whiteboard Drawing Over the Network
-   **The Problem:** Sending raw mouse coordinates over the network can cause jagged, disconnected lines for other viewers.
-   **The Solution:** Engineered a custom data router that broadcasts coordinate packages with a specialized flag (`isNewStroke`). This allows multiple users to paint on the same canvas seamlessly without drawing anomalies.

## 🚀 Getting Started

### Prerequisites
*   Python 3.x Installed

### Installation & Run
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Install dependencies:
   ```bash
   pip install flask flask-socketio
   ```
3. Run the application:
   ```bash
   python app.py
   ```
4. Open your browser and navigate to `http://127.0.0.1:5001`
